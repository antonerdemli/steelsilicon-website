# Steel & Silicon — версия для GitHub Pages

Эта папка содержит готовую статическую версию сайта. Сервер, Node.js и установка программ для публикации не требуются.

## Как опубликовать через браузер

1. Создайте в GitHub новый публичный репозиторий.
2. Откройте репозиторий и выберите **Add file → Upload files**.
3. Загрузите содержимое этой папки. Файл `index.html` должен находиться в корне репозитория, а не внутри дополнительной вложенной папки.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**;
   - Branch: **main**;
   - Folder: **/(root)**.
7. Нажмите **Save** и дождитесь появления ссылки на сайт.

Сайт работает и в проектном адресе вида `https://USERNAME.github.io/REPOSITORY/`.

## Подключение steelsilicon.com

Сначала проверьте сайт по адресу GitHub Pages. После этого укажите `steelsilicon.com` в поле **Custom domain** раздела **Settings → Pages** и выполните показанные GitHub настройки DNS.

Сейчас домен направлен на прежний хостинг. Не изменяйте DNS до проверки версии на GitHub Pages, иначе основной сайт временно перестанет открываться.

Файл `CNAME.example` содержит пример значения домена. Сам GitHub обычно создает рабочий файл `CNAME` после настройки Custom domain.

## Где менять сайт

- `content.js` — тексты на английском, русском, немецком и испанском языках;
- `styles.css` — оформление сайта;
- `site.js` — переключение языков и раскрытие карточек;
- изображения можно заменить файлами с теми же именами;
- `index.html` — структура главной страницы;
- `.nojekyll` — служебный файл GitHub Pages, его нужно сохранить.

После изменения файлов загрузите их в тот же репозиторий с заменой старых версий.
